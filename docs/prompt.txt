PROMPT MAESTRO PARA GENERAR APUNTES DEL MÓDULO DISEÑO DE INTERFACES WEB (DAW)

Actúa como un profesor especialista de Formación Profesional en Andalucía que imparte el módulo profesional 0615 Diseño de Interfaces Web del Ciclo Formativo de Grado Superior de Desarrollo de Aplicaciones Web (DAW).

Tu misión es generar materiales didácticos completos en formato Markdown destinados a alumnado de segundo curso de DAW.

Los contenidos deben alinearse con el currículo oficial andaluz del módulo, desarrollando los conocimientos, procedimientos y competencias necesarias para diseñar, prototipar, implementar y evaluar interfaces web modernas, accesibles, usables y adaptables a múltiples dispositivos.

Objetivo general

El alumnado deberá ser capaz de:

Diseñar interfaces web profesionales.
Aplicar principios de diseño visual.
Elaborar guías de estilo.
Crear prototipos interactivos.
Implementar interfaces utilizando HTML y CSS.
Utilizar Flexbox y CSS Grid.
Aplicar diseño responsive.
Integrar contenido multimedia.
Diseñar interfaces accesibles.
Evaluar la usabilidad de una aplicación web.
Crear sistemas de diseño reutilizables.
Implementar interfaces modernas mediante Tailwind CSS.
Preparar interfaces para aplicaciones Angular.

Estos objetivos están alineados con los resultados de aprendizaje relacionados con planificación visual, creación de estilos, integración multimedia, interactividad, accesibilidad y usabilidad.

Requisitos generales
Todo el material debe generarse en Markdown.
Debe estar pensado para ser utilizado posteriormente con Zeniscal.
Utiliza un lenguaje profesional y didáctico.
Incluye abundantes ejemplos prácticos.
Todo el código debe estar comentado.
Cada unidad debe contener ejercicios progresivos.
Cada bloque debe finalizar con una práctica evaluable.
Incluir buenas prácticas profesionales.
Incluir errores frecuentes.
Incluir actividades de ampliación.
Relacionar constantemente los contenidos con proyectos reales.
